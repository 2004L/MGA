## 2. 零依赖档 Demo（开箱即验）

只需 Python 3.10+ 与两个纯 Python 包（`numpy`、`pillow`）。

```bash
git clone https://github.com/2004L/MGA.git
cd MGA

# 安装仅有的两个运行依赖
pip install numpy pillow

# 跑零依赖档 demo：纯数学 ETA + CV 合成帧，不碰真桌面
PYTHONPATH=src python -m demo_dino_real --sim
```

Windows PowerShell 等价：

```powershell
git clone https://github.com/2004L/MGA.git
cd MGA
pip install numpy pillow
$env:PYTHONPATH = "src"
python -m demo_dino_real --sim
```

退出码应为 `0`，终端会打印 System1 / System2 分流统计与 MotionModel 单帧耗时。

## 3. 实测数据（已在本机跑通）

`demo_dino_real --sim` 在某次 1200 帧合成场景下的实测：

| 指标 | 数值 |
|------|------|
| System1 静默帧（直接放行） | 18996（≈97.5%） |
| System2 关键帧（触发大脑） | 487（≈2.5%） |
| 关键帧触发次数 | 487 |
| 成功躲过（预判帧生效） | 487 |
| 漏判撞车 | 0 |
| MotionModel 纯数学 ETA 均值 | 1.64 µs / 帧 |
| 有效帧率 | ≈220 fps |
| 退出码 | 0 |

结论：双系统分流正确，预判帧（System1）承担绝大多数静默帧、仅在真风险时唤醒大脑（System2），
全程零漏判；纯数学 ETA 开销可忽略，满足实时性预算。

## 4. 三档 Demo 说明

| 档位 | 命令 | 依赖 | 说明 |
|------|------|------|------|
| A（验收档） | `python -m demo_dino_real --sim` | numpy, pillow | 纯数学 + CV 合成帧，**不碰真桌面**，开箱即验 |
| B（真机档） | `python -m demo_dino_real --frames 1200` | pyautogui, opencv, mss | 真机桌面采集，需图形会话 |
| C（全功能档） | `python -m demo_locator` / `main --real` / `ui_server` | mga-lora + SAM3 venv + GPU | 完整感知+执行链，权重与 venv 见 `blobs/` |

评审默认走 **A 档**即可确认架构与分流正确性；B / C 档用于深度联调。
