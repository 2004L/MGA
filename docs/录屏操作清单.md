# Chrome 小恐龙 · AI Computer Use 录屏操作清单

> 项目：MGA Dino Pilot —— 感知(**YOLOE 深度学习主通道 + 形状佐证 CV 兜底**) → 预判(MotionModel 纯数学) → 决策(System1/System2) → 执行(SendInput 原生键盘注入)
> 录屏目标：展示「AI 自己看屏幕、自己判断、自己按键」的完整 computer use 闭环。

## 一、首次准备（只做一次）
1. 打开 Chrome，**普通权限**启动（不要右键「以管理员身份运行」——否则 UIPI 会吞掉 AI 发的键，恐龙不跳）。
2. 断网，或地址栏输入 `chrome://dino`，让小恐龙跑起来。
3. 框选游戏区（省得每次自动量）：
   打开终端（项目目录），运行：
   ```
   python -m demo_dino_real --pick-region
   ```
   弹全屏图 → 鼠标左键拖拽框住游戏区 → 回车确认。
   框选结果存进 `.dino_region.json`，之后自动复用。

## 二、日常录屏（每次）
1. 双击项目里的 **`run_dino.bat`**（会自动装依赖、自动量/复用游戏区、弹出标注窗口）。
2. 脚本会**自动找窗口 → 最小化则还原 → 聚焦 → 点击游戏区**获焦，不需要手动点；保持 Chrome 在前台别切走即可。
3. 手机相机 / OBS 录窗口：
   **窗口标题 = `MGA Dino Pilot AI View`**
   窗口里能看到：游戏截图 + 恐龙绿框 + 障碍红框(仙人掌)/黄框(鸟) + HUD(ETA/动作/System1·System2/后端/IL/fps/延迟)。
4. 录 3 分钟，看 AI 能跑多远。撞死会自动停，也可随时 Ctrl+C 停。

## 三、关键提示
- **Chrome 必须普通权限**：启动后看窗口 HUD 那行 `IL=medium`；若显示 `IL=high` 说明 Chrome 是管理员，键会被 UIPI 吞掉，需改用普通权限重启 Chrome。
- **感知层是形状佐证，不是纯颜色**：颜色初筛 + 地面周期点纹 + 恐龙剪影几何 + 障碍形状，多证据融合，能区分真游戏和桌面横线/任务栏，不会再把桌面当游戏。
- **预判是纯数学，零神经网络**：`MotionModel` 最小二乘估水平速度 → 算到达恐龙的时间(ETA)，延迟 ~1.7µs。
- **深度学习主通道 = YOLOE 开放词汇**（`src/perception/dino_detect.py`）：按语义名直接检测 `dinosaur / cactus / bird`，不受单色配色影响。
  权重放 `blobs/weights/yoloe*.pt` 即自动启用；**没有权重就自动降级 CV，不报错、不中断**（首帧有一次约 2 秒的权重查找，之后不再重试）。
  强制只用 CV：`python -m demo_dino_real --no-dl`。
- **ScreenParser 的职责是 GUI 桌面访问，不是游戏元素**：它的 55 类词汇是 Button/Text/Icon，看不见恐龙/仙人掌；本项目用它在 `exec/gui_agent.locate_game_window` 里定位 Chrome 窗口（OS 级坐标，零误差）。
  所以分工是：窗口定位=ScreenParser/OS，游戏障碍=YOLOE，兜底=CV。

## 四、故障排查
| 现象 | 原因 | 处理 |
|------|------|------|
| 窗口自己关了 / 没弹 | 进程不在交互桌面 session | 直接双击 `run_dino.bat`（交互进程才显示窗口） |
| 报「请先打开 chrome://dino」 | 没开游戏或游戏区变了 | 开 `chrome://dino`，或重跑 `--pick-region` |
| 恐龙不跳（按键无效） | Chrome 管理员权限被 UIPI 吞键 | 普通权限重启 Chrome |
| `No module named demo_dino_real` | PYTHONPATH 没设 | 用 `run_dino.bat` 启动（已内置 `set PYTHONPATH`），勿手动粘命令到 cmd |
| 帧率低(<10fps) 漏判 | 截图后端慢 | 已用 mss 直读帧缓冲，正常 15-30fps；若仍低，缩小游戏窗口或重框游戏区 |
| 首帧卡约 2 秒 | 深度学习权重查找(只一次) | 正常；想跳过就加 `--no-dl`，或把 `yoloe*.pt` 放进 `blobs/weights` 让它真正启用 |
