# 桌面 Computer Use 能力 · 老板演示讲稿

> 适用对象：技术/业务老板   |   建议时长：8–12 分钟   |   一键启动：`python src/desktop_capability_demo.py`
> 风格：白话为主，术语配一句解析；演示前先 `python src/desktop_capability_demo.py` 跑一遍，照着屏幕念下面绿色【讲解】即可。

---

## 0. 开场白（约 30 秒，照念）

"今天给大家看的是我们自研的**桌面 AI 操作能力**——简单说，就是让 AI 能'看懂'电脑屏幕、'知道'界面上哪个是按钮、哪个是输入框，并且**只在安全范围内**帮人点一点、填一填。

它不是玩具：视觉模型是本地跑的（数据不出机器），还带了一道**安全门禁**——删东西、付钱、乱发消息这种高危动作，AI 自己绝对做不了，必须人来确认。下面我用四个场景把它跑给大家看。"

---

## 场景 1 · 视觉感知（SAM3 概念分割，约 2 分钟）

**【演示操作】** 直接跑脚本，等它加载完（首次约 30–40 秒，取决于 OS 文件缓存；演示前可先空跑一次预热，之后同进程内结果秒出），屏幕上出现一张标注图。

**【屏幕现象】** 一张微信截图，上面用**青色框**圈出一堆图标/按钮，每个框中心有**黄色十字**，左上角信息面板写着 `backend=semantic`、检出了多少个元素、置信度多少。

**【讲解 · 白话】**
"这就是 AI 的'眼睛'。我刚才只说了一句——'帮我把画面里的图标找出来'。它没用任何预定义的模板，就凭一句话，把屏幕上所有图标、按钮、窗口**一个个抠了出来**，连轮廓都标好了。黄十字是它算出的'点击点'。

我们用的模型叫 **SAM3**（Meta 的），它厉害在'开放词汇'——你随便说一个东西的名字，它就能找，不局限于'按钮/输入框'这几类固定词。"

**【技术点 · 一句话】**
"SAM3 给的是**像素级 mask（轮廓）**，质心当点击点比传统检测框中心更稳；本地 3.4GB 模型、6GB 显存即可跑，单次推理约 7–8 秒（常驻进程复用后）。"

---

## 场景 2 · 三级降级链（约 1.5 分钟）

**【演示操作】** 脚本自动接着跑，终端打印两行对比。

**【屏幕现象】** 终端显示：
```
L1.5 主升级通道 SAM3 : backend=semantic  元素=N
L3   CV 几何兜底     : backend=cv        元素=M
```

**【讲解 · 白话】**
"任何 AI 模型都有可能偶尔抽风或者没装上。我们设计了一条**降级链**：主通道（SAM3）如果出问题，立刻自动换一条最朴素的兜底——用几何形状去认按钮（方形、带边框的就算），保证'至少能点'。

最关键的不是技术多花哨，而是**诚实**：系统会实时标注'现在走的是哪条路'（backend 字段），绝不假装主通道一直正常、偷偷用兜底糊弄你。"

**【技术点 · 一句话】**
"三级降级：L1 专用 UI 检测器(55 类) → L1.5 SAM3 开放词汇 → L3 CV 几何兜底；`active_backend` 强制如实标注，架构真相可追溯。"

---

## 场景 3 · 意图级安全门禁（重点，约 2.5 分钟）

**【演示操作】** 脚本接着跑，终端一条条打印语句和决策。

**【屏幕现象】** 类似：
```
把下载文件夹里的大文件删除      delete     BLOCK        OK
给客户发送这封邮件              send       BLOCK        OK
用微信支付付这笔订单            payment    NEED_CONFIRM OK
在表单里填好姓名和电话          normal      ALLOW        OK
不发送，只是存草稿              normal      ALLOW        OK
```

**【讲解 · 白话】**
"这是我最想给大家看的——**安全**。前面再能看、再能点，要是它乱删你文件、乱发消息、乱付钱，那叫失控。

我们加了一道**语义门禁**，在 AI 真正动手之前先判断'你想干啥'：
- **删东西** → 直接拦死，AI 连准备都不做；
- **付钱** → 它可以帮你填好单子，但**必须你本人点一下确认**才真正付；
- **发消息** → 默认也是拦死的，只有你明确授权、且限定单一对象时才放；
- 普通填表、整理文件 → 正常放行。

最后那句'**不发送，只是存草稿**'——注意，它连'否定句'都听得懂，不会误拦。"

**【技术点 · 一句话】**
"IntentGate 三态：BLOCK(删除/未授权发送) / NEED_CONFIRM(支付) / ALLOW(正常)；删除与支付是**物理红线**，代码层不可绕过；否定式（不/别/勿）正确取消意图。"

---

## 场景 4 · 自主桌面操作（可选，需现场 --live，约 2 分钟）

**【演示操作】** 现场确认后执行：`python src/desktop_capability_demo.py --live`，它会自动开 Chrome 玩小恐龙。

**【讲解 · 白话】**
"前面是'看'，这个是'做'。我们已经验证过：AI 能自己打开浏览器、找到小恐龙游戏、并且自己玩起来；也能在微信里替你回消息。

但'做'这件事我们收得很紧——替你回消息时，**鼠标一旦动一下就立刻停手交还给你**；而且绝不碰删除、绝不碰支付。把控制权随时交还真人，是我们做自主操作的第一原则。"

**【技术点 · 一句话】**
"DesktopAgent 闭环 perceive→plan→gate→act→verify；HumanOverrideMonitor 轮询真人鼠标活动，一动即取消；微信替聊受 IntentGate 授权约束。"

## 收尾（约 30 秒，照念）

"总结一下：我们能**看懂屏幕**（SAM3 本地模型）、**稳得住**（三级降级不中断）、**管得住**（安全门禁拦高危）、并且在你授权下**帮得上手**（自主操作随时可接管）。

整套能力**本地运行、数据不出机器**，对咱们这种在意合规和安全的业务场景，是最关键的底座。接下来的重点是把它接到具体业务流程里。"

## Q&A 应对（老板常问，提前备好）

**Q：实时性怎么样？卡不卡？**
A：单次视觉感知约 7–8 秒（模型 3.4GB，已用常驻进程把重复加载压掉）。连续帧实时性还在优化，当前定位是'准优先于快'，关键操作不追求每帧。

**Q：认得准吗？会不会点错？**
A：GUI 元素用专用 55 类检测器（按钮/输入框最准）；开放词汇（任意物体）走 SAM3，在公开分割基准上超过同类基线。所有点击前都过安全门禁，点错高危目标会被拦。

**Q：数据安全吗？要上云吗？**
A：视觉模型和门禁**全本地**，截图不出本机。只有可选的'大模型理解'环节才走 API，且可关。

**Q：和 OpenAI Operator / Claude Computer Use 比？**
A：它们依赖云端、数据出机器；我们是本地优先 + 开放词汇 + 自带安全门禁，更适合对合规敏感的业务，也能接任意桌面应用。

**Q：现在能用到生产吗？**
A：感知 + 门禁已真通可演示；自主操作（小恐龙/微信替聊）已验证但默认保守开启。下一步是按具体业务流程接入，建议先挑一个低风险场景（如表单填报）落地。
